# 📝 To-Do App

A simple, modern To-Do app built with HTML, CSS, and JavaScript.

## Features
- ✅ Add, edit, and delete tasks
- ✅ Mark tasks as complete
- ✅ Dark/Light mode toggle
- ✅ Tasks persist after page refresh (using localStorage)

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
